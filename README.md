# TableReserve Bot

Telegram bot for restaurants that shows real-time available slots, lets guests book/reschedule/cancel with a short reference code, and sends reminders and owner notifications.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
